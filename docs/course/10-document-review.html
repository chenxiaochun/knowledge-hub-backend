目标与验收

前置：第 4 课 MQ 发布已通；建议已完成 课 09（至少会用 @Roles）。

本课：用 kh_document_review 记录审核流水；强制审核（不再直发）；补齐归档 / 存草稿 / 编辑保护 / 审核角色。

验收
  1. 上传 → Draft；submit-review → PendingReview，表中一条 review_result IS NULL
  2. approve：结案 + Published + MQ INDEX；reject：回 Draft，comment 必填
  3. 没有可用的直发：删掉或禁用 PUT …/publish；发布只经 approve
  4. archive / save-as-draft：Published → 归档或草稿，并清索引
  5. PUT …/:id 可改正文/标题；PendingReview 时 400
  6. 待办 / 通过 / 驳回仅 ADMIN 或 REVIEWER
与课 4 的关系：课 4 用「管理员直发 + MQ」先把管道跑通。 本课起一律强制审核，不要再保留 DOCUMENT_REQUIRE_APPROVAL 开关。 若 .env 里还有该变量，删掉以免误导。

概念

上传 ──► Draft ──submit-review──► PendingReview │ │ │ ┌─────┴─────┐ │ approve reject │ │ │ │ Published ◄── Draft │ │ │ ┌────────┼────────┐ │ archive save-draft 再 submit │ │ │ │ │ Archived Draft PendingReview │ （已发布再提审：先 afterUnpublish） 唯一入索引时机：approve → afterPublish 清索引时机：archive / save-draft / 已发布再提审 / 软删除
操作前状态后状态索引
upload—Draft—
submit-reviewDraft / PublishedPendingReview若来自 Published → 清
approvePendingReviewPublished建（afterPublish）
rejectPendingReviewDraft—
archivePublishedArchived清
save-as-draftPublishedDraft清
updateDraft / Published / Archived不变不自动重建；改后再提审

    export enum DocumentStatus {
  Draft = 0,
  Published = 1,
  Archived = 2,
  PendingReview = 3,
}

export const DOCUMENT_STATUS_LABEL: Record<DocumentStatus, string> = {
  [DocumentStatus.Draft]: '草稿',
  [DocumentStatus.Published]: '已发布',
  [DocumentStatus.Archived]: '已归档',
  [DocumentStatus.PendingReview]: '待审核',
};

export function canSubmitReview(status: DocumentStatus): boolean {
  return status === DocumentStatus.Draft || status === DocumentStatus.Published;
}

export function canArchive(status: DocumentStatus): boolean {
  return status === DocumentStatus.Published;
}

/** 待审核期间禁止改正文/标题 */
export function canEditContent(status: DocumentStatus): boolean {
  return (
    status === DocumentStatus.Draft ||
    status === DocumentStatus.Published ||
    status === DocumentStatus.Archived
  );
}

  3. DocumentReviewService

    src/document/document-review.service.ts

    不注入 ConfigService，不读任何「是否需审」开关。

    import {
  BadRequestException,
  Injectable,
  Logger,
  NotFoundException,
} from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { IsNull, Repository } from 'typeorm';
import { nextSnowflakeId } from '../common/snowflake-id';
import { DocumentPipelinePublisher } from '../mq/document-pipeline.publisher';
import { DocumentStatus } from './document-status';
import { DocumentEntity } from './entities/document.entity';
import {
  DocumentReviewEntity,
  ReviewResult,
} from './entities/document-review.entity';
import type { AuthUser } from '../auth/auth-user.interface';

@Injectable()
export class DocumentReviewService {
  private readonly logger = new Logger(DocumentReviewService.name);

  constructor(
    @InjectRepository(DocumentReviewEntity)
    private readonly reviewRepo: Repository<DocumentReviewEntity>,
    @InjectRepository(DocumentEntity)
    private readonly docRepo: Repository<DocumentEntity>,
    private readonly pipelinePublisher: DocumentPipelinePublisher,
  ) {}

  private async findDoc(id: string) {
    const doc = await this.docRepo.findOne({ where: { id, deleted: false } });
    if (!doc) throw new NotFoundException('文档不存在');
    return doc;
  }

  async submitForReview(documentId: string, actor: AuthUser) {
    const doc = await this.findDoc(documentId);
    if (
      doc.status !== DocumentStatus.Draft &&
      doc.status !== DocumentStatus.Published
    ) {
      throw new BadRequestException('只有草稿或已发布文档可以提交审核');
    }

    const pending = await this.reviewRepo.findOne({
      where: { documentId, reviewResult: IsNull() },
    });
    if (pending) throw new BadRequestException('该文档已有待审核任务');

    const beforeStatus = doc.status;
    const review = this.reviewRepo.create({
      id: nextSnowflakeId(),
      documentId,
      beforeStatus,
    });
    await this.reviewRepo.save(review);

    doc.status = DocumentStatus.PendingReview;
    await this.docRepo.save(doc);

    // 已发布再提审：审核期间不可检索
    if (beforeStatus === DocumentStatus.Published) {
      try {
        await this.pipelinePublisher.afterUnpublish(documentId);
      } catch (e) {
        this.logger.warn(`提审后清索引失败：${e}`);
      }
    }

    this.logger.log(`已提交审核 reviewId=${review.id} by ${actor.username}`);
    return { document: doc, review };
  }

  async approveReview(reviewId: string, actor: AuthUser, comment?: string) {
    const review = await this.reviewRepo.findOne({ where: { id: reviewId } });
    if (!review || review.reviewResult != null) {
      throw new BadRequestException('待审任务不存在或已结案');
    }

    review.reviewResult = ReviewResult.Approved;
    review.reviewerId = actor.userId;
    review.reviewerName = actor.username;
    review.reviewComment = comment ?? null;
    review.reviewedAt = new Date();
    await this.reviewRepo.save(review);

    const doc = await this.findDoc(review.documentId);
    doc.status = DocumentStatus.Published;
    doc.publishTime = new Date();
    const saved = await this.docRepo.save(doc);

    // 唯一发布入口：投递失败不回滚（与课 4 一致）
    await this.pipelinePublisher.afterPublish(saved.id);
    this.logger.log(`审核通过 reviewId=${reviewId}`);
    return saved;
  }

  async rejectReview(reviewId: string, actor: AuthUser, comment: string) {
    if (!comment?.trim()) {
      throw new BadRequestException('驳回意见不能为空');
    }
    const review = await this.reviewRepo.findOne({ where: { id: reviewId } });
    if (!review || review.reviewResult != null) {
      throw new BadRequestException('待审任务不存在或已结案');
    }

    review.reviewResult = ReviewResult.Rejected;
    review.reviewerId = actor.userId;
    review.reviewerName = actor.username;
    review.reviewComment = comment;
    review.reviewedAt = new Date();
    await this.reviewRepo.save(review);

    const doc = await this.findDoc(review.documentId);
    doc.status = DocumentStatus.Draft;
    await this.docRepo.save(doc);
    this.logger.log(`审核驳回 reviewId=${reviewId}`);
    return doc;
  }

  async listPending() {
    return this.reviewRepo.find({
      where: { reviewResult: IsNull() },
      order: { createdAt: 'DESC' },
    });
  }
}
    待审条件用 reviewResult: IsNull()，不要用 reviewerId: IsNull()。

  5. 归档 / 存为草稿

    src/document/document.service.ts

    async archive(id: string) {
  const doc = await this.docRepo.findOne({ where: { id, deleted: false } });
  if (!doc) throw new NotFoundException('文档不存在');
  if (!canArchive(doc.status)) {
    throw new BadRequestException('只有已发布文档可以归档');
  }
  doc.status = DocumentStatus.Archived;
  const saved = await this.docRepo.save(doc);
  try {
    await this.pipelinePublisher.afterUnpublish(saved.id);
  } catch (e) {
    this.logger.warn(`归档清索引失败：${e}`);
  }
  return saved;
}

async saveAsDraft(id: string) {
  const doc = await this.docRepo.findOne({ where: { id, deleted: false } });
  if (!doc) throw new NotFoundException('文档不存在');
  if (doc.status !== DocumentStatus.Published) {
    throw new BadRequestException('只有已发布文档可以保存为草稿');
  }
  doc.status = DocumentStatus.Draft;
  const saved = await this.docRepo.save(doc);
  try {
    // 注意：这里是 afterUnpublish，不是 afterPublish
    await this.pipelinePublisher.afterUnpublish(saved.id);
  } catch (e) {
    this.logger.warn(`下架清索引失败：${e}`);
  }
  return saved;
}

    async updateDocument(id: string, dto: UpdateDocumentDto) {
  const doc = await this.docRepo.findOne({ where: { id, deleted: false } });
  if (!doc) throw new NotFoundException('文档不存在');
  if (!canEditContent(doc.status)) {
    throw new BadRequestException('待审核文档不可编辑');
  }

  // 用 !== undefined，不要写成 if (!dto.title)（空字符串 / 未传会搞反）
  if (dto.title !== undefined) doc.title = dto.title;
  if (dto.tags !== undefined) doc.tags = dto.tags;

  if (dto.content !== undefined) {
    const summary = dto.content.slice(0, 200);
    await this.contentModel.updateOne(
      { documentId: id, deleted: false },
      {
        $set: {
          content: dto.content,
          contentLength: dto.content.length,
          contentSummary: summary,
        },
      },
    );
    doc.wordCount = this.countWords(dto.content);
  }

  // 已发布改正文：不在这里重建索引；应再走 submit-review（会先清索引）→ approve
  return this.docRepo.save(doc);
}
    产品规则（本课约定）：编辑不自动改状态、不投 MQ。 已发布文档改完后，作者再 submit-review；审核通过才重新入索引。

    路由顺序（必做）：所有 reviews/* 静态路径必须写在 @Get(':id') / @Put(':id') 之前。 否则 GET …/reviews/pending 会被当成查文档。 
    @Controller('document')
export class DocumentController {
  constructor(
    private readonly documentService: DocumentService,
    private readonly reviewService: DocumentReviewService,
  ) {}

  @Post('upload/parse')
  @UseInterceptors(FileInterceptor('file', { limits: { fileSize: 10 * 1024 * 1024 } }))
  uploadAndParse(…) { … }

  // ✅ 静态路径在前
  @Get('reviews/pending')
  @Roles(RoleCode.ADMIN, RoleCode.REVIEWER)
  listPending() {
    return this.reviewService.listPending();
  }

  @Put('reviews/:reviewId/approve')
  @Roles(RoleCode.ADMIN, RoleCode.REVIEWER)

    @CurrentUser() user: AuthUser,
    @Body() body: { comment?: string },
  ) {
    return this.reviewService.approveReview(reviewId, user, body?.comment ?? '');
  }

  @Put('reviews/:reviewId/reject')
  @Roles(RoleCode.ADMIN, RoleCode.REVIEWER)
  reject(
    @Param('reviewId') reviewId: string,
    @CurrentUser() user: AuthUser,
    @Body() body: { comment: string },
  ) {
    return this.reviewService.rejectReview(reviewId, user, body.comment);
  }

  @Get()
  page(@Query() query: QueryDocumentDto) {
    return this.documentService.pageDocuments(query);
  }

  @Put(':id/submit-review')
  submitReview(@Param('id') id: string, @CurrentUser() user: AuthUser) {
    return this.reviewService.submitForReview(id, user);
  }

  @Put(':id/archive')
  @Roles(RoleCode.ADMIN)
  archive(@Param('id') id: string) {
    return this.documentService.archive(id);
  }

  @Put(':id/save-as-draft')
  saveAsDraft(@Param('id') id: string) {
    return this.documentService.saveAsDraft(id);
  }

  @Put(':id')
  update(@Param('id') id: string, @Body() dto: UpdateDocumentDto) {

  @Get(':id')
  detail(@Param('id') id: string) {
    return this.documentService.getDetail(id);
  }

  @Delete(':id')
  @Roles(RoleCode.ADMIN)

设计决策

为什么本课不设 DOCUMENT_REQUIRE_APPROVAL？

课 4 已经用直发验证了 MQ。进阶状态机若再保留开关，容易半套半用（管理员仍绕过审核台）。 练习仓约定：发布 = 审核通过，一条路径更清晰。

为什么 approve 按 reviewId 而不是 documentId？

同一文档可有多条历史；结案必须对准「那一条待审」。列表接口返回 reviewId 给审核人。

为什么「待审」用 review_result IS NULL？

待审语义是「还没出结果」。审核人字段结案时才填；用 reviewer 判断会和「预分配审核人」等扩展冲突。

为什么编辑不立刻重建索引？

强制审核下，索引内容应与「已通过审核的版本」一致。改完再提审 → 先清旧索引 → 通过后再建，避免未审文进入检索。

与 origin v6 差异

本课约定origin v6 / 常见练习仓坑
强制审核，无环境开关origin 可能仍有 DOCUMENT_REQUIRE_APPROVAL；练习仓按本课，不抄开关
无 PUT …/publish 直发若仍直发 + afterPublish，审核台形同虚设
Published 再提审先 afterUnpublish常漏清索引 → 审核中仍能搜到旧文
待审判定 reviewResult IS NULL误用 reviewerId IS NULL
saveAsDraft 必须 afterUnpublish误写成 afterPublish 会把草稿再索引进去
update 用 !== undefinedif (!dto.title) 会把「要清空」与「未传」搞反
审核接口 @Roles(ADMIN, REVIEWER)漏写则任意登录用户可审
分页 tasks / history 可选本课步骤可先只做 pending 列表

对齐练习（自查清单）

原则：讲义只教你怎么写，不替你改练习仓 src/。 按下面顺序对照自己的实现；卡住再打开 origin v6。

练习 0 · 路由顺序与列名

  1. 把 reviews/* 全部挪到 @Get(':id') / @Put(':id') 之前。
  2. Entity：reviewer_id / reviewed_at（勿写成 review_id / review_at）。

自测：GET …/reviews/pending 返回数组，而不是「文档不存在」。

练习 1 · 待审条件

// ❌ where: { documentId, reviewerId: IsNull() }
// ✅
where: { documentId, reviewResult: IsNull() }

练习 2 · 确认已去掉直发

  • Controller 无 publish，或调用即 400「请提交审核…」
  • 仅 approve 调用 afterPublish
  • .env 无 DOCUMENT_REQUIRE_APPROVAL

练习 3 · 已发布再提审先清索引

见上文 submitForReview 中 beforeStatus === Published 分支。

自测：已发布能搜到 → submit → 立刻搜不到 → approve → 又能搜到。

练习 4 · archive / save-as-draft / update / Roles

  • saveAsDraft 用 afterUnpublish
  • updateDocument 用 canEditContent + !== undefined
  • pending / approve / reject 带 @Roles(ADMIN, REVIEWER)

练习 5 · 审核工作台增强（可选）

  • GET …/reviews/tasks?status=pending|approved|rejected
  • GET …/:id/reviews/history

建议动手顺序

  1. 练习 0 → 1（路由、待审条件）
  2. 练习 2 → 3（强制审核 + 提审清索引）
  3. 练习 4（归档 / 草稿 / 编辑 / 角色）
  4. 有余力再做练习 5
