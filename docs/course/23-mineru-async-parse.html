一句话目标

在课 12「同步本地解析 → Markdown」已通的前提下，把 复杂 PDF / 多格式统一解析 旁路到 MinerU： 上传立刻返回，RabbitMQ 后台调 MinerU Tasks API，写回 Mongo； MinerU 挂掉时 降级回本地 parser。

自测通过： ① DOCUMENT_PARSE_BACKEND=mineru 时，上传 PDF 立即返回 status=Parsing，几秒～几分钟后变 Draft 且正文可读； ② 关掉 MinerU 且 PARSE_FALLBACK_LOCAL=true 时仍能出草稿； ③ DOCUMENT_PARSE_BACKEND=local 行为与课 12 一致（同步）； ④ txt/md 可配置为始终本地秒解析（不必过 MinerU）。
前置：课 12 的 FileParserService + RustFS 可用；课 4 的 RabbitMQ 可收发。 本课不删本地 parser，只加旁路与异步外壳。 官方 Docker 主推 Linux + NVIDIA；macOS 个人练习见「起 MinerU」一节。

为什么要换 / 为什么不全砍本地

痛点课 12 本地链MinerU
扫描件 / 复杂排版 PDF pdf-parse 偏文本层，版面弱 版面分析 + OCR + 公式/表更强
多格式统一 每格式一套库（mammoth / exceljs / …） PDF / Office / 图可走同一服务
耗时 毫秒～秒，适合同步 HTTP 秒～分钟，必须异步
运维 纯 Node 依赖 要起 Python/模型服务（吃 CPU/GPU）

个人练习推荐方案： MinerU 旁路 + 策略开关 + 本地降级， 不要一上来删掉课 12 的 parser——方便对比质量、也方便 MinerU 没起来时继续写别的课。

费用：自建软件本身免费（Apache 2.0 + 补充条款；个人练习远低于商业许可门槛）。 真实成本是机器、磁盘模型、电费/云账单。云 API 才按次收费——本课不走云。

概念与数据流

客户端 POST /documents/upload/parse │ ├─ ① 原件 → RustFS（prefix=documents）→ fileUrl ├─ ② Postgres：建文档 status=Parsing（或 Draft 若走 local 同步） ├─ ③ Mongo：先写占位 content=""（或「解析中…」） └─ ④ 投递 RabbitMQ：document.parse.queue │ ▼ DocumentParseConsumer │ ├─ backend=mineru → MinerUClient.parse(buffer) │ POST /v1/tasks → PUT 上传字节 → 轮询 GET /v1/tasks/{id} │ → 下载 result_url（ZIP）→ 抽出 *.md ├─ 失败且允许降级 → FileParserService.parse（课 12） └─ 写回 Mongo content + status=Draft（失败 → ParseFailed）

前端类比

后端前端感觉
同步 FileParserService.parse点上传转圈到出结果（课 12）
异步 + MQ + Parsing 状态先出「处理中」卡片，再轮询/WS 刷新正文
DOCUMENT_PARSE_BACKEND功能开关 / 灰度：local | mineru | auto
MinerU HTTP 服务独立微服务；Nest 只当客户端

状态怎么加

现有 DocumentStatus：Draft / Published / Archived / PendingReview。 本课加两个：

值含义可否编辑正文可否提交审核
Parsing = 4后台解析中否否
ParseFailed = 5解析失败（可重试）否（或仅允许重试）否
Draft = 0解析成功可编辑是是
也可用独立字段 parseStatus，不动业务状态机。练习版用扩展枚举更少文件改动； 若你后面要「解析中也能改标题」，再拆字段不迟。

起 MinerU（个人练习）

目标：本机有一个 HTTP 入口，健康检查 GET /v1/health 返回 200。Nest 用 MINERU_BASE_URL 指向它。

路径 A · Linux / 有 NVIDIA：官方 Docker API

按官方文档构建 mineru:4 后：

# 在 MinerU 仓库根目录
docker compose -f docker/compose.yaml --profile api up -d

# 健康检查
curl -s http://127.0.0.1:8000/v1/health | jq .

协议以官方为准：MinerU 4.1+ 主路径是异步 Tasks API（POST /v1/tasks），不是旧的 /v1/parse。

路径 B · macOS（推荐练习）

官方 Docker 部署不适合 macOS 做 GPU 加速；个人练习更稳的是 pip/uv 装 mineru，用 pipeline 后端（可 CPU），再起 api-server。 
# 示例（版本以官方 README 为准，安装后看 --help）
uv pip install -U "mineru[all]"

# 起 API（命令名随版本可能是 mineru-kit api-server）
mineru-kit api-server --host 0.0.0.0 --port 8000

curl -s http://127.0.0.1:8000/v1/health

第一次会下模型，磁盘与内存要留足。CPU 跑复杂 PDF 会慢——正好用来验证「异步 + 轮询」设计。

改练习仓 docker-compose.yml

课 12 起的依赖（Postgres / Mongo / RabbitMQ / RustFS…）已经在仓库根目录 docker-compose.yml 里。本课把 MinerU API 也挂进去， 用 profiles: [mineru]，默认 docker compose up 不会拉起它（避免没 GPU / Mac 同学一上来就被拖垮）。

3. 和「官方独立 compose」怎么选

做法适合注意
练习仓 docker-compose.yml + profile mineru 想一个 compose 管齐依赖、和课 12 同一套习惯 必须先本地 docker build 出 mineru:4；镜像体积大
MinerU 仓库自己的 docker/compose.yaml --profile api 想跟官方文档逐步对齐、少改练习仓 两套 compose 并存；端口仍是 8000，Nest 只认 URL
本机 mineru-kit api-server（路径 B） macOS / 无 NVIDIA 的个人练习 不必改练习仓 compose；.env 指 127.0.0.1:8000 即可
Nest 没有放进本仓 compose 时，不要写 MINERU_BASE_URL=http://mineru-api:8000（那是容器网络内的服务名）。 宿主机进程请用 http://127.0.0.1:8000。 若以后把 API 也容器化，再改成服务名，并让它们加入同一 network。
个人练习建议：Mac 先走路径 B 跑通课； 有 Linux GPU 再把上面服务粘进 compose 并打开 deploy.resources。 讲义里的 YAML 是「怎么改文件」的模板，不是保证你当前环境一次成功的镜像配方—— entrypoint / 环境变量以官方当前 Dockerfile 为准，有出入就对照改。

export enum DocumentStatus {
  Draft = 0,
  Published = 1,
  Archived = 2,
  PendingReview = 3,
  Parsing = 4,

}

export const DOCUMENT_STATUS_LABEL: Record<DocumentStatus, string> = {
  [DocumentStatus.Draft]: '草稿',
  [DocumentStatus.Published]: '已发布',
  [DocumentStatus.Archived]: '已归档',
  [DocumentStatus.PendingReview]: '待审核',
  [DocumentStatus.Parsing]: '解析中',
  [DocumentStatus.ParseFailed]: '解析失败',
};

export function canSubmitReview(status: DocumentStatus): boolean {
  return status === DocumentStatus.Draft || status === DocumentStatus.Published;
}

export function canArchive(status: DocumentStatus): boolean {
  return status === DocumentStatus.Published;
}

/** 解析中 / 失败 / 待审核：禁止改正文 */
export function canEditContent(status: DocumentStatus): boolean {
  return (
    status === DocumentStatus.Draft ||
    status === DocumentStatus.Published ||
    status === DocumentStatus.Archived
  );
}

  3. MinerU 客户端（Tasks API 精简版）

    src/document/parser/mineru.client.ts
    下列实现按 MinerU 4.1 Tasks API 思路编写：建任务 → PUT 字节 → 轮询 → 下载 result_url。字段名以你本机 /openapi.json 为准，有出入就改映射，不要死磕粘贴。 
    import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import JSZip from 'jszip';

export interface MineruParseInput {
  fileName: string;
  buffer: Buffer;
}

@Injectable()
export class MineruClient {
  private readonly logger = new Logger(MineruClient.name);
  private readonly baseUrl: string;
  private readonly apiKey: string;
  private readonly pollIntervalMs: number;
  private readonly pollTimeoutMs: number;

  constructor(private readonly config: ConfigService) {
    this.baseUrl = this.config.get('MINERU_BASE_URL', 'http://127.0.0.1:8000').replace(/\/$/, '');
    this.apiKey = this.config.get('MINERU_API_KEY', '') ?? '';
    this.pollIntervalMs = Number(this.config.get('MINERU_POLL_INTERVAL_MS', 2000));
    this.pollTimeoutMs = Number(this.config.get('MINERU_POLL_TIMEOUT_MS', 600000));
  }

  async health(): Promise<boolean> {
    try {
      const res = await fetch(`${this.baseUrl}/v1/health`);
      return res.ok;
    } catch {
      return false;
    }
  }

  /** 返回 Markdown 正文 */
  async parseToMarkdown(input: MineruParseInput): Promise<string> {
    const headers = this.authHeaders({ 'Content-Type': 'application/json' });

    const createRes = await fetch(`${this.baseUrl}/v1/tasks`, {
      method: 'POST',
      headers,
      body: JSON.stringify({
        files: [
          {
            file_name: input.fileName,
            bytes: input.buffer.byteLength,
          },
        ],
        output_formats: ['default'],
      }),
    });
    if (!createRes.ok) {
      throw new Error(`MinerU 建任务失败: ${createRes.status} ${await createRes.text()}`);
    }
    const created = (await createRes.json()) as {
      task_id: string;
      files: Array<{
        file_id: string;
        status: string;
        upload?: { url: string; headers?: Record<string, string> };
      }>;
    };

    const file = created.files?.[0];
    if (!file) throw new Error('MinerU 建任务未返回 files[0]');

    if (file.upload?.url) {
      const putHeaders = { ...(file.upload.headers ?? {}) };
      const putRes = await fetch(file.upload.url, {
        method: 'PUT',
        headers: putHeaders,
        body: new Uint8Array(input.buffer),
      });
      if (!putRes.ok) {
        throw new Error(`MinerU 上传失败: ${putRes.status} ${await putRes.text()}`);
      }
    }

    const detail = await this.pollUntilDone(created.task_id);
    const done = detail.files?.[0];
    if (!done || done.status !== 'completed' || !done.result_url) {
      throw new Error(`MinerU 未完成: status=${done?.status ?? 'unknown'}`);
    }

    const zipBuf = Buffer.from(await (await fetch(done.result_url)).arrayBuffer());
    return this.extractMarkdownFromZip(zipBuf);
  }

  private authHeaders(extra: Record<string, string> = {}): Record<string, string> {
    const h = { ...extra };
    if (this.apiKey) h.Authorization = `Bearer ${this.apiKey}`;
    return h;
  }

  private async pollUntilDone(taskId: string) {
    const started = Date.now();
    while (Date.now() - started < this.pollTimeoutMs) {
      const res = await fetch(`${this.baseUrl}/v1/tasks/${encodeURIComponent(taskId)}`, {
        headers: this.authHeaders(),
      });
      if (!res.ok) throw new Error(`MinerU 查询失败: ${res.status}`);
      const detail = (await res.json()) as {
        files: Array<{ status: string; result_url?: string; error?: { message?: string } }>;
      };
      const f = detail.files?.[0];
      if (f?.status === 'completed') return detail;
      if (f?.status === 'failed') {
        throw new Error(`MinerU 解析失败: ${f.error?.message ?? 'unknown'}`);
      }
      await new Promise((r) => setTimeout(r, this.pollIntervalMs));
    }
    throw new Error(`MinerU 轮询超时 (${this.pollTimeoutMs}ms)`);
  }

  private async extractMarkdownFromZip(zipBuf: Buffer): Promise<string> {
    const zip = await JSZip.loadAsync(zipBuf);
    const mdName = Object.keys(zip.files).find((n) => n.toLowerCase().endsWith('.md'));
    if (!mdName) throw new Error('MinerU 结果 ZIP 中未找到 .md');
    const text = await zip.files[mdName].async('string');
    if (!text.trim()) throw new Error('MinerU Markdown 为空');
    this.logger.log(`MinerU 解析完成: md=${mdName}, chars=${text.length}`);
    return text;
  }
}

    若依赖没有 jszip：pnpm add jszip（课 12 若已装可跳过）。

  4. 解析编排服务

    src/document/document-parse.service.ts 
    import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { InjectModel } from '@nestjs/mongoose';
import { InjectRepository } from '@nestjs/typeorm';
import { Model } from 'mongoose';
import { Repository } from 'typeorm';

import { RustfsService } from '../storage/rustfs.service';
import { DocumentStatus } from './document-status';
import { DocumentEntity } from './entities/document.entity';
import { FileParserService } from './parser/file-parser.service';
import { MineruClient } from './parser/mineru.client';
import { DocumentContent, DocumentContentDocument } from './schemas/document-content.schema';

@Injectable()
export class DocumentParseService {
  private readonly logger = new Logger(DocumentParseService.name);

  constructor(
    private readonly config: ConfigService,
    private readonly mineru: MineruClient,
    private readonly localParser: FileParserService,
    private readonly storage: RustfsService,
    @InjectRepository(DocumentEntity) private readonly docRepo: Repository<DocumentEntity>,
    @InjectModel(DocumentContent.name)
    private readonly contentModel: Model<DocumentContentDocument>,
  ) {}

  /** Consumer 入口：按策略解析并落库 */
  async runJob(input: {
    documentId: string;
    fileUrl: string;
    fileName: string;
    mimetype?: string;
  }): Promise<void> {
    const doc = await this.docRepo.findOne({ where: { id: input.documentId, deleted: false } });
    if (!doc) {
      this.logger.warn(`文档不存在，跳过: ${input.documentId}`);
      return;
    }

    const buffer = await this.downloadOriginal(input.fileUrl);
    const ext = this.localParser.getExtension(input.fileName);
    let markdown = '';
    let used: 'mineru' | 'local' = 'local';

    try {
      const preferMineru = await this.shouldUseMineru(ext);
      if (preferMineru) {
        try {
          markdown = await this.mineru.parseToMarkdown({ fileName: input.fileName, buffer });
          used = 'mineru';
        } catch (err) {
          const msg = err instanceof Error ? err.message : String(err);
          this.logger.warn(`MinerU 失败: ${msg}`);
          if (!this.fallbackLocalEnabled()) throw err;
          markdown = await this.localParser.parse({
            originalname: input.fileName,
            buffer,
            size: buffer.length,
            mimetype: input.mimetype,
          });
          used = 'local';
        }
      } else {
        markdown = await this.localParser.parse({
          originalname: input.fileName,
          buffer,
          size: buffer.length,
          mimetype: input.mimetype,
        });
      }

      await this.contentModel.updateOne(
        { documentId: input.documentId, deleted: false },
        {
          $set: {
            content: markdown,
            contentLength: markdown.length,
            contentSummary: markdown.slice(0, 200),
          },
        },
      );
      doc.status = DocumentStatus.Draft;
      doc.wordCount = markdown.length;
      await this.docRepo.save(doc);
      this.logger.log(`解析成功 documentId=${input.documentId} via=${used} chars=${markdown.length}`);
    } catch (err) {
      const msg = err instanceof Error ? err.message : String(err);
      this.logger.error(`解析失败 documentId=${input.documentId}: ${msg}`);
      doc.status = DocumentStatus.ParseFailed;
      await this.docRepo.save(doc);
      await this.contentModel.updateOne(
        { documentId: input.documentId, deleted: false },
        { $set: { content: `解析失败：${msg}`, contentSummary: '解析失败', contentLength: 0 } },
      );
    }
  }

  private fallbackLocalEnabled(): boolean {
    return this.config.get('PARSE_FALLBACK_LOCAL', 'true') !== 'false';
  }

  private async shouldUseMineru(ext: string): Promise<boolean> {
    const localExts = (this.config.get('PARSE_LOCAL_EXTS', 'txt,md') || '')
      .split(',')
      .map((s) => s.trim().toLowerCase())
      .filter(Boolean);
    if (localExts.includes(ext)) return false;

    const backend = (this.config.get('DOCUMENT_PARSE_BACKEND', 'auto') || 'auto').toLowerCase();
    if (backend === 'local') return false;
    if (backend === 'mineru') return true;
    // auto
    return this.mineru.health();
  }

  /** 练习版：若 RustfsService 已有 getObject/download，优先用；否则用 fileUrl HTTP GET */
  private async downloadOriginal(fileUrl: string): Promise<Buffer> {
    if (typeof (this.storage as any).downloadBytes === 'function') {
      return (this.storage as any).downloadBytes(fileUrl);
    }
    const res = await fetch(fileUrl);
    if (!res.ok) throw new Error(`下载原件失败: ${res.status} ${fileUrl}`);
    return Buffer.from(await res.arrayBuffer());
  }
}
    若 RustFS 桶是私有读，fetch(fileUrl) 会 403——请在 RustfsService 补 downloadBytes（GetObject）， 或在消息里带临时本地路径（练习可先把上传文件另存 /tmp）。

  5. Publisher / Consumer

    src/mq/document-parse.publisher.ts 
    import { Injectable, Logger } from '@nestjs/common';
import { randomUUID } from 'crypto';
import { DOCUMENT_PARSE_EXCHANGE, DOCUMENT_PARSE_RK } from './mq.constant';
import { DocumentParseMessage } from './messages/pipeline.messages';
import { RabbitMQService } from './rabbitmq.service';

@Injectable()
export class DocumentParsePublisher {
  private readonly logger = new Logger(DocumentParsePublisher.name);
  constructor(private readonly rabbit: RabbitMQService) {}

  async enqueue(input: {
    documentId: string;
    fileUrl: string;
    fileName: string;
    mimetype?: string;
  }) {
    const message: DocumentParseMessage = {
      taskId: randomUUID(),
      type: 'PARSE',
      ...input,
    };
    const ok = await this.rabbit.publish(DOCUMENT_PARSE_EXCHANGE, DOCUMENT_PARSE_RK, message);
    this.logger.log(
      `解析任务${ok ? '已投递' : '投递失败'}：documentId=${input.documentId}, taskId=${message.taskId}`,
    );
    return message.taskId;
  }
}
    src/mq/document-parse.consumer.ts 
    import { Injectable, Logger } from '@nestjs/common';
import { ConsumeMessage } from 'amqplib';
import { DocumentParseService } from '../document/document-parse.service';
import { DOCUMENT_PARSE_QUEUE } from './mq.constant';
import { DocumentParseMessage } from './messages/pipeline.messages';
import { RabbitMQService } from './rabbitmq.service';

@Injectable()
export class DocumentParseConsumer {
  private readonly logger = new Logger(DocumentParseConsumer.name);

  constructor(
    private readonly rabbit: RabbitMQService,
    private readonly parseService: DocumentParseService,
  ) {
    this.rabbit.registerHandler(DOCUMENT_PARSE_QUEUE, (msg) => this.handle(msg));
  }

  private async handle(msg: ConsumeMessage) {
    const body = JSON.parse(msg.content.toString('utf8')) as DocumentParseMessage;
    this.logger.log(`[Parse] taskId=${body.taskId}, documentId=${body.documentId}`);
    await this.parseService.runJob(body);
  }
}

    在 MqModule 的 providers / exports 里注册 Publisher；Consumer 放进 providers（与 DocumentPipelineConsumer 同级）。注意 DocumentParseService 依赖 Document 模块实体——可用 forwardRef 或把 ParseService 放在 DocumentModule 并 export，Consumer 注入它。

设计决策

决策选择为什么
替换范围 旁路 + 开关，不删课 12 个人练习要对比质量；MinerU 挂了还能继续开发
时序 异步 MQ MinerU 可能分钟级；同步会拖垮 HTTP / 网关超时
原件位置 先 RustFS 再解析 消息体不塞大文件；失败可重试同一 URL
txt/md 默认同步本地 无版面问题，过 MinerU 浪费
协议 Tasks API（4.1+） 官方主路径；旧 /v1/parse 已淘汰
与发布管线关系 解析成功只到 Draft 审核/RAG/KG 仍走课 4+ 发布后链路，边界清晰
