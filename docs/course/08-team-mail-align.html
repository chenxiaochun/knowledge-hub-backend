一句话目标

补齐与 origin 的「周边能力」：Team 简易 CRUD， 以及邮件激活 / 重置密码的接线方式；最后用清单对照 练习版还简化了什么，方便你决定要不要继续对齐。

自测：能创建/分页团队； 能说清邮件链路涉及哪些类（即使本地用 Ethereal / 日志代替真发信）。

逐步实现

  1. Team Entity + CRUD（完整精简）

    src/team/entities/team.entity.ts

    import {
  Column,
  CreateDateColumn,
  Entity,
  PrimaryColumn,
  UpdateDateColumn,
} from 'typeorm';
import { bigintTransformer } from '../../common/transformers/bigint.transformer';

@Entity('kh_team')
export class TeamEntity {
  @PrimaryColumn({ type: 'bigint', transformer: bigintTransformer })
  id: string;

  @Column({ type: 'varchar', length: 100 })
  name: string;

  @Column({
    name: 'parent_id',
    type: 'bigint',
    nullable: true,
    transformer: bigintTransformer,
  })
  parentId?: string | null;

  @Column({ type: 'varchar', length: 255, nullable: true })
  remark?: string | null;

  @CreateDateColumn({ name: 'created_at' })
  createdAt: Date;

  @UpdateDateColumn({ name: 'updated_at' })
  updatedAt: Date;

  @Column({ type: 'boolean', default: false })
  deleted: boolean;
}

    Service：create / update / softDelete / page（ILIKE name）；Controller：@Roles(RoleCode.ADMIN) + /teams。AppModule entities 注册 TeamEntity。

  2. 邮件能力怎么对齐（可先读后做）

    origin 链路：

    register(requireEmailVerification) → EmailActivationService.createToken → EmailService.sendActivationEmail → GET /auth/verify-email?token= → 用户 emailVerified=1 重置密码： send-code → Redis/存储验证码 → reset

    练习版最小实现：

    • pnpm add @nestjs-modules/mailer nodemailer
    • MAIL_* 指向 Mailhog / Ethereal；开发环境也可 EmailService 只 Logger.log 打印链接
    • 激活 token 可先放 Postgres 一张小表，或 Redis（第 2 课曾留空）
    不必一次抄全 origin。先保证「能发出去 / 能点开激活」一条路径即可。

与 origin 差异

本课是收尾对齐课：刻意保留简化，让你带着清单去读 origin，而不是假装已经 1:1。

常见报错 / 学习建议

  • 卡在邮件：先 Logger 打印激活链接，再换真实 SMTP。
  • 卡在权限：先 Roles，再补 Permission 表与 Guard。
  • 对照阅读顺序建议：auth.module → document-review → pipeline.orchestrator → graph-build。
